# feat/pwa-install — install it as an app on the phone

"Add to Home Screen" (iPhone Safari: Share → Add to Home Screen; Android Chrome: menu → Install app) now gives the battalion medallion as the app icon, the name "גדוד 8239", and opens full screen without browser chrome, in the dark brand colour.

- `apps/web/public/manifest.webmanifest` — name, RTL/Hebrew, `display: standalone`, theme colour, icons (192, 512, and a maskable 512 for Android's adaptive shapes).
- `apps/web/public/icons/*` and `icon.svg` — generated by `apps/web/scripts/make-icons.mjs` (the same medallion geometry as `Logo.tsx`, on a dial of tick marks). Everything important sits in the central 80% circle, so it survives Android's crop. Re-run the script to regenerate; the PNGs are committed.
- `apps/web/index.html` — manifest link, `apple-touch-icon` (iOS ignores the manifest icons), favicon, iOS standalone meta.

No service worker on purpose: an offline cache of an app that signs for weapons would risk showing stale quantities. It needs a connection, as before.
