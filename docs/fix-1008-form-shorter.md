# 1008 form: shorter sheet, roomier item rows

The printed 1008 no longer stretches to the full A4 height. The sheet is about 70% of the page (`min-height: 208mm`, 207mm in print), item rows are taller (22pt) so there is room to write per item, and the signing blocks are tighter (signature box 20mm). A form with many lines still grows past that and flows over several pages (`MAX_FILL_LINES`).
